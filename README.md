# dm-apt-predict
서울 아파트 실거래가와 주변 입지 변수를 활용한 머신러닝 기반 가격 분석 및 예측 프로젝트

## 1. Project Overview

본 프로젝트는 서울시 아파트 실거래가 데이터를 기반으로 아파트 가격에 영향을 미치는 요인을 분석하고, 머신러닝 모델을 활용해 아파트 가격을 예측하는 것을 목표로 한다.

초기 분석 범위는 서울 전체로 설정한다. 이후 탐색적 데이터 분석 결과에 따라 가격 경향성이 뚜렷하거나 거래량이 충분한 일부 자치구를 선정하여 분석 범위를 조정할 수 있다.

## 2. Research Questions

본 프로젝트에서 다루고자 하는 주요 질문은 다음과 같다.

- 서울 아파트 가격에 가장 큰 영향을 미치는 변수는 무엇인가?
- 전용면적, 층, 건축년도, 입지 조건 등은 아파트 가격과 어떤 관계를 가지는가?
- 지하철 접근성, 중심업무지구와의 거리, 병원 및 대형마트 접근성 등 생활 인프라 변수는 가격 예측 성능을 높이는가?
- 시중 통화량과 같은 거시경제 변수는 아파트 가격 변화와 관련이 있는가?
- 서울 전체를 대상으로 한 모델과 특정 자치구를 대상으로 한 모델의 예측 성능은 어떻게 다른가?

## 3. Target Variable

예측 대상 변수는 다음 중 하나로 설정할 수 있다.

- 거래금액
- ㎡당 거래가격

초기 모델링에서는 단지 간 면적 차이를 보정하기 위해 `㎡당 거래가격`을 주요 타깃 변수로 사용하는 것을 우선 고려한다.

```text
price_per_m2 = 거래금액 / 전용면적
```

## 4. Data Scope

### Region

- 1차 범위: 서울특별시 전체
- 추후 조정 가능 범위:
  - 거래량이 많은 자치구
  - 가격 변동성이 큰 자치구
  - 경향성이 뚜렷한 일부 자치구

### Period

초기에는 데이터 수집 및 정제 과정을 안정적으로 구축하기 위해 최근 1년 데이터를 우선 사용한다.

이후 프로젝트 진행 상황에 따라 다음과 같이 확장한다.

- 최근 1년
- 최근 3년
- 최근 5년

기간별 모델 성능을 비교하여 데이터 기간이 예측 성능에 미치는 영향도 함께 확인할 수 있다.

## 5. Data Sources

사용 예정 데이터와 예상 출처는 다음과 같다.

| 데이터 | 주요 용도 | 예상 출처 |
| --- | --- | --- |
| 아파트 실거래가 | 가격 예측의 핵심 데이터 | 국토교통부 실거래가 공개시스템, 공공데이터포털 API |
| 법정동 및 행정구역 정보 | 지역 변수 정리 | 행정안전부, 공공데이터포털 |
| 지하철역 위치 | 최근접 지하철 거리 계산 | 서울 열린데이터광장 |
| 중심업무지구 위치 | CBD 거리 계산 | 직접 정의 또는 공공 자료 기반 설정 |
| 대형마트 위치 | 생활 인프라 변수 | 공공데이터, 지도 API, 수동 구축 |
| 병원 위치 | 의료 접근성 변수 | 공공데이터포털, 보건의료빅데이터개방시스템 |
| 시중 통화량 M2 | 거시경제 변수 | 한국은행 경제통계시스템 ECOS |

## 6. Candidate Variables

### Raw Variables

아파트 실거래가 데이터에서 우선 사용할 원천 변수는 다음과 같다.

| 변수 | 설명 |
| --- | --- |
| 거래금액 | 실제 거래된 아파트 가격 |
| 전용면적 | 아파트 전용면적 |
| 층 | 거래된 세대의 층 |
| 건축년도 | 아파트 준공 연도 |
| 법정동 | 법정동 단위 지역 정보 |
| 구 | 서울시 자치구 |
| 거래년월 | 거래 발생 연월 |
| 아파트명 | 단지명 |
| 주소 또는 지번 | 위치 정보 생성에 활용 |

### Derived Variables

추가로 생성하거나 외부 데이터와 결합하여 사용할 파생 변수는 다음과 같다.

| 변수 | 설명 |
| --- | --- |
| 연식 | 거래년도 - 건축년도 |
| 거래월 | 거래 시점의 월 |
| 거래분기 | 거래 시점의 분기 |
| ㎡당 거래가격 | 거래금액 / 전용면적 |
| 최근접 지하철 거리 | 해당 아파트에서 가장 가까운 지하철역까지의 거리 |
| 중심업무지구 거리 | 주요 업무지구까지의 거리 |
| 인근 대형마트 수 또는 거리 | 반경 기준 대형마트 접근성 |
| 인근 병원 수 또는 거리 | 상급종합병원, 종합병원 접근성 |
| 층수비 | 해당 층 / 전체 층수, 전체 층수 확보 가능 시 사용 |
| M2 통화량 | 거래년월 기준 시중 통화량 |

## 8. Workflow

### Step 1. Repository Setup

- GitHub 레포지토리 생성
- 기본 폴더 구조 생성
- `README.md`, `.gitignore`, `requirements.txt` 작성
- 팀원별 역할 및 작업 규칙 정리

### Step 2. Apartment Transaction Data Collection

- 국토교통부 아파트 실거래가 데이터 수집
- 서울시 전체 데이터를 기준으로 수집
- 우선 최근 1년 데이터를 수집하여 코드와 데이터 구조를 검증
- 이후 최근 3년 또는 5년으로 기간 확장

### Step 3. Data Cleaning

- 거래금액 숫자형 변환
- 전용면적, 층, 건축년도 등 주요 변수 타입 정리
- 결측치 확인 및 처리
- 이상치 확인
- 계약 해제 건 또는 비정상 거래 여부 확인
- 자치구, 법정동, 거래년월 변수 정리

### Step 4. Feature Engineering

- 연식 생성
- 거래월 및 거래분기 생성
- ㎡당 거래가격 생성
- 주소 기반 위도/경도 생성
- 지하철역, 병원, 대형마트 등 외부 시설과 거리 변수 생성
- 거래년월 기준 M2 통화량 병합

### Step 5. Exploratory Data Analysis

- 서울 전체 거래량 추이 확인
- 자치구별 평균 가격 비교
- 자치구별 ㎡당 가격 분포 확인
- 전용면적, 연식, 층, 지하철 거리 등 주요 변수와 가격의 관계 분석
- 이상치 및 결측치 패턴 확인
- 분석 범위를 서울 전체로 유지할지, 일부 자치구로 축소할지 판단

### Step 6. Modeling

딥러닝을 제외한 머신러닝 회귀 모델을 사용한다.

후보 모델:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost 또는 LightGBM

초기에는 단순 모델부터 시작하여 점진적으로 복잡한 모델을 비교한다.

### Step 7. Evaluation

모델 평가지표는 다음을 사용한다.

- MAE
- RMSE
- R2 Score
- MAPE

모델별 성능을 비교하고, 서울 전체 모델과 특정 자치구 모델의 차이를 분석한다.

### Step 8. Interpretation

- 변수 중요도 분석
- 주요 변수와 가격의 관계 해석
- 자치구별 예측 오차 비교
- 입지 변수 추가 전후 성능 비교
- M2 통화량 변수의 영향 확인

### Step 9. Report and Presentation

- 데이터 수집 과정 정리
- 변수 설명 및 전처리 과정 정리
- EDA 결과 시각화
- 모델링 결과 및 성능 비교
- 변수 중요도 및 해석
- 한계점과 개선 방향 제시
